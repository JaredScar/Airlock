Airlock

A broadcast delay that stays on your PC. It holds the stream, catches what should not air, and lets you undo a redaction before the delay runs out.

What it holds back

  • Word-list bleeps, spoken phone numbers, and names you mark as private.
  • A context check for platform rules, on this machine unless you opt into a cloud model.
  • On-screen keys and personal info. Secrets are pixelated. The clip above is that path on a generated frame.

Point OBS or Streamlabs Desktop at rtmp://127.0.0.1:1935/live. The platform key stays in the operating-system keychain.
