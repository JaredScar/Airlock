What leaves this PC

This is the list of data that can leave the machine, and the data that stays.

  • Word lists, spoken checks, and on-screen text recognition stay on this PC.
  • Private terms stay on this PC. The desktop app seals them and keeps the key in the OS keychain. This preview has no keychain, so terms stay in this browser's profile.
  • The local judge talks to Ollama on this machine. That transcript is not sent to a cloud model.
  • The cloud judge sends the transcript to Anthropic only if "Transcript text may leave this PC" is checked and a key is saved. Private terms are not included. The key goes to the OS keychain.
  • A stream key stays in the OS keychain. It is not written into settings or logs.
  • Crash and latency reports stay off unless you opt in below, and they never include the transcript or a key. No destination is configured, so nothing is sent.

Speech model

Picked from GPU memory when a broadcast starts. 8 GB or more uses the large turbo model. 4 GB uses the distilled model. Anything smaller, or no GPU, uses small.en on the CPU. The file is kept only if its checksum matches.

License

Word lists, the dump button, and spoken personal info stay on without a key. The context judge, on-screen scanning, and the cloud judge are the Pro checks. The key is verified on this PC.

Reset

Restores the shipped delay, categories, and empty rule lists. Private terms return to the demo school name.
