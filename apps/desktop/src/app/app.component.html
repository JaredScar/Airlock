OBS. Settings → Stream → Service: Custom. Server rtmp://127.0.0.1:1935/live. Stream key airlock. Airlock can open its listener when OBS opens. That switch is in Settings. Closing this window leaves Airlock in the tray.

Streamlabs Desktop. Settings → Stream → Stream to custom ingest. Stream type: Custom Streaming Server. URL rtmp://127.0.0.1:1935/live. Stream key airlock.

  • Encoder: NVENC, or x264 without it. CBR, 15000 Kbps at 1080p, keyframe interval 2 seconds.
  • Audio: 48 kHz, 320 Kbps. Video passes through untouched.
  • In OBS, set a backup server to the platform itself. If Airlock stops, OBS continues the broadcast there.
  • Streamlabs chat, alerts, and widgets that follow the platform connection stay quiet. Streamlabs is publishing to this PC, and Airlock is the app connected to Twitch, YouTube, or Kick.
